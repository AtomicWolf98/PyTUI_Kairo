## Architecture

```
Composer (app-level) ──submit──▶ KairoTuiApp._submit_turn ──▶ kernel.submit(TurnRequest)
                                                                    │
EventPump (last sequence) ◀── kernel.events.subscribe ──────────────┘
   │  EventAction / RecoveryAction
   ▼
AppStore (pure reducer)  ── store.subscribe ──▶ ChatScreen (30 FPS _flush timer)
      │                       └───────────────▶ InspectorPanel (Activity tab)
      │ session_timeline(state, session_id)   (pure, chat_model.py)
      ▼
Timeline widgets: Static(Markdown) · Collapsible(reasoning) · ToolCard · PlanCard · InteractionCard
```

- `KairoTuiApp` keeps the kernel + store; page mounts live in `#page` (`_show_page`).
- All events flow through the store reducer first, then widgets re-render on store change. The Chat page never calls the kernel for reads — only for `submit` / `cancel` / `interactions.respond`.
- Pure logic lives outside Textual: the reducer in `store.py` and the timeline model in `chat_model.py`, so unit tests never construct widgets.

## Global Constraints

1. **Public kernel API only** — imports of `kairo_kernel`, `kairo_kernel.contracts.*`, `kairo_kernel.ports.*`, `kairo_kernel.errors` are allowed; anything else (`engine`, `runtime`, `services`, `factory`, `kernel`, `tools`, …) is forbidden (AST boundary). Implement test doubles against public ports (`ToolRegistryPort`, `ToolPort`, `AuthorizationPolicyPort`, `ProviderPort`) — never import `tests/kernel/*`.
2. **30 FPS batch flush** — the reducer applies every event synchronously; widget **refresh** is throttled to a `set_interval(1/30)` timer.
3. **Force flush before terminal events** — any folded event that is terminal (TURN terminal status, MESSAGE `completed`, INTERACTION `resolved`) renders the timeline immediately, synchronously.
4. **Timeout display-only** — countdown text only; the TUI never calls `interactions.respond` on expiry (the kernel broker resolves expiry with `safe_default`, fail-closed).
5. **Per-session single turn, cross-session parallel** — the kernel's `SessionTurnSupervisor` enforces admission; the UI only reflects (`active_turns`), never blocks.
6. **Switching pages/sessions never cancels background turns** — Esc cancels the foreground (active session's) turn only; page navigation and session selection dispatch store actions only.
7. **No `typing import Any`**; `mypy frontends/tui` clean (whole tree); `ruff check frontends/tui` clean.
8. **No git commits.**
9. All collections stay keyed by kernel IDs (message/turn/tool/interaction/session) — never match display text (tui_plan.md normalization rule).

## Streaming data shape — evidence & decision

Read `kairo_kernel/engine/turns.py` (`_provider_round`, `_execute`, `_plan`) and `kairo_kernel/contracts/events.py`:

- The engine emits **incremental deltas** as `MessageEvent(message_id, action, content)` where `content` is only the newly-arrived `ContentBlock`s of the current provider round:
  - `action="delta"` for chat rounds, `action="plan_delta"` for plan rounds (turns.py:465-475). Each delta is a partial append; `message_id` is fresh per provider round.
  - `action="completed"` carries the **full** round content `stream.blocks + stream.tool_calls` (turns.py:303) — tool-call blocks never stream as deltas, they appear only here.
- Multiple provider rounds (tool loops, plan→chat) produce multiple assistant `message_id`s per turn; tool messages (`MessageRole.TOOL`) are **never** emitted as MessageEvents — the TUI learns about tools only via `ToolEvent` (`requested`/`started`/`output`/`completed`).
- User messages are **never** emitted as events (turns.py:268-275 appends to history only) — the TUI inserts its own user bubble at submit time (`UserTurnAction`).
- Plan messages are emitted as ordinary MessageEvents (no `MessageKind` on `MessageEvent`); the TUI marks a turn's latest assistant message as a plan when a `PLAN_APPROVAL` interaction is requested.

**Reducer rule (decided with the evidence above):** on `delta`/`plan_delta` → upsert the message **appending** `content`; on `completed` → upsert **replacing** `content` (authoritative, includes tool-call blocks). Because the final event is a full replacement, no content is ever lost or duplicated. **The 30 FPS batch applies to RENDER batching only** (Textual `refresh`/`update` throttling); the store writes are synchronous per event on the UI thread.

def fold_event(state: AppState, event: KernelEvent) -> AppState:
    state = _replace(state, last_event_sequence=event.sequence, events=_push_event(state.events, event))
    payload = event.payload
    if isinstance(payload, TurnEvent):
        ...  # unchanged
    if isinstance(payload, MessageEvent):
        return _fold_message(state, event, payload)
    if isinstance(payload, ToolEvent):
        return _fold_tool(state, event, payload)
    if isinstance(payload, InteractionEvent) and payload.action == "requested" and payload.request is not None:
        state = _replace(
            state, pending_interactions=_upsert_interaction(state.pending_interactions, payload.request)
        )
        if payload.request.kind is InteractionKind.PLAN_APPROVAL:
            state = _replace(state, messages=_mark_plan_for_turn(state.messages, str(payload.request.turn_id)))
        return state
    if isinstance(payload, InteractionEvent) and payload.action == "resolved" and payload.interaction_id is not None:
        return _replace(
            state, pending_interactions=tuple(
                item for item in state.pending_interactions if item.interaction_id != payload.interaction_id
            )
        )
    if isinstance(payload, ChangeEvent) and event.event_type is EventType.WORKSPACE_CHANGED:
        return _replace(state, workspace_revision=payload.revision)
    return state

def _fold_message(state: AppState, event: KernelEvent, payload: MessageEvent) -> AppState:
    if payload.action not in ("delta", "plan_delta", "completed"):
        return state
    if payload.action == "completed":
        record = ChatMessage(
            str(payload.message_id), str(event.session_id or ""), str(event.turn_id or ""),
            event.sequence, MessageRole.ASSISTANT, MessageKind.CHAT, payload.content,
            complete=True, revision=1,
        )
        return _replace(state, messages=_upsert_message(state.messages, record))
    existing = _find_message(state.messages, payload.message_id)
    if existing is None:
        record = ChatMessage(
            str(payload.message_id), str(event.session_id or ""), str(event.turn_id or ""),
            event.sequence, MessageRole.ASSISTANT, MessageKind.CHAT, payload.content,
            revision=1,
        )
        return _replace(state, messages=_upsert_message(state.messages, record))
    appended = ChatMessage(
        existing.message_id, existing.session_id, existing.turn_id, event.sequence,
        existing.role, existing.kind, existing.content + payload.content,
        existing.complete, existing.plan, existing.revision + 1,
    )
    return _replace(state, messages=_upsert_message(state.messages, appended))

def _fold_tool(state: AppState, event: KernelEvent, payload: ToolEvent) -> AppState:
    if payload.invocation is None or payload.action not in ("requested", "started", "output", "completed"):
        return state
    invocation = payload.invocation
    card = _find_tool_card(state.tool_cards, invocation.tool_call_id)
    if card is None:
        card = ToolCard(str(invocation.tool_call_id), str(invocation.session_id), str(invocation.turn_id),
                        invocation.name, invocation.arguments, payload.action, sequence=event.sequence)
    else:
        stage = payload.action
        card = ToolCard(card.tool_call_id, card.session_id, card.turn_id, card.name, card.arguments,
                        stage, card.output + ((payload.output,) if payload.output is not None else ()),
                        payload.result if payload.action == "completed" else card.result,
                        event.sequence)
    return _replace(state, tool_cards=_upsert_tool_card(state.tool_cards, card))

def _mark_plan_for_turn(messages: tuple[ChatMessage, ...], turn_id: str) -> tuple[ChatMessage, ...]:
    indexes = [i for i, m in enumerate(messages)
               if m.turn_id == turn_id and m.role is MessageRole.ASSISTANT and not m.plan]
    if not indexes:
        return messages
    i = indexes[-1]  # the turn's most recent assistant message = the plan
    m = messages[i]
    marked = ChatMessage(m.message_id, m.session_id, m.turn_id, m.sequence, m.role, m.kind,
                         m.content, m.complete, True, m.revision + 1)
    return messages[:i] + (marked,) + messages[i + 1:]
```

Helpers: `_find_message(messages, message_id) -> ChatMessage | None`, `_upsert_message(messages, record)` (replace in place by `message_id`, else append), `_find_tool_card` / `_upsert_tool_card` (same by `tool_call_id`).

    state = _replace(
        state, kernel_status=action.status, sessions=action.sessions,
        active_turns=action.turns, pending_interactions=action.pending,
        workspace_root=action.workspace_root, workspace_revision=action.workspace_revision,

                     messages_epoch=state.messages_epoch + 1)
    return state

def _merge_messages(existing: tuple[ChatMessage, ...], recovered: tuple[ChatMessage, ...]) -> tuple[ChatMessage, ...]:
    by_id = {m.message_id: m for m in existing}
    for m in recovered:
        by_id[m.message_id] = m
    return tuple(sorted(by_id.values(), key=lambda m: m.sequence))
```

**Mapping rules (implement exactly)**

- `UserItem` per `user_turns` entry for the session, ordered by `sequence`; `status = state.turn_status.get(turn_id)`.
- Per `ChatMessage` of the session ordered by `sequence`: `plan=True` → `PlanItem` (text = concatenated `TextBlock.text`; `streaming = not complete`; attach the pending `PLAN_APPROVAL` interaction for its `turn_id`); otherwise text blocks of one message concatenate into one `TextItem` (`streaming = not complete`), `ReasoningBlock`s become `ReasoningItem`s, and **tool cards come from `state.tool_cards`** (not from content blocks) keyed by `session_id` and ordered by `sequence`, attaching the pending `TOOL_APPROVAL` interaction for the card's `turn_id`.
- Every pending interaction for the session that was not attached to a card/plan becomes a trailing `InteractionItem` (covers `TEXT_INPUT` and post-recovery plan approvals whose message was lost).
- Ordering: merge user/message/tool items by `sequence`; trailing interaction items append at the end (they are current state, not history).
- `should_force_flush(event)`: `TurnEvent` with `status in TERMINAL_STATUSES`, or `MessageEvent` with `action == "completed"`, or `InteractionEvent` with `action == "resolved"` → `True`.
- `countdown_seconds(expires_at)`: `None` when `expires_at is None`, else `max(0.0, (expires_at - datetime.now(timezone.utc)).total_seconds())`.
- `last_user_text`: text of the last `UserTurn` for the session by `sequence`; `""` when none.

```python
class ChatScreen(Container):
    def __init__(self, app) -> None:
        super().__init__(id="chat-screen")
        self._app = app
        self.kernel = app.kernel
        self.store = app.store
        self._dirty = False
        self._last_epoch = -1
        self._widgets: dict[str, Widget] = {}

    def compose(self) -> ComposeResult:
        yield Static(id="chat-header")
        yield VerticalScroll(id="chat-timeline")
        yield TurnStatusBar(id="turn-status")   # Task 5

    def on_mount(self) -> None:
        self._flush_timer = self.set_interval(1 / 30, self._flush)
        self.store.subscribe(self._on_store)
        self._render_header()
        self._rebind()

    def on_unmount(self) -> None:
        self.store.unsubscribe(self._on_store)
        self._flush_timer.stop()

    def _on_store(self, state: AppState) -> None:
        if state.messages_epoch != self._last_epoch:
            self._last_epoch = state.messages_epoch
            self._rebind()
            return
        newest = state.events[-1] if state.events else None
        if newest is not None and should_force_flush(newest):
            self._dirty = False
            self._render_timeline()
        else:
            self._dirty = True
        self._render_header()

    def _flush(self) -> None:
        if self._dirty:
            self._dirty = False
            self._render_timeline()

    def _rebind(self) -> None:
        """Full rebuild: recovery rebind or session switch. Drop and re-mount every widget."""
        self._widgets.clear()
        timeline = self.query_one("#chat-timeline", VerticalScroll)
        timeline.remove_children()
        self._render_timeline()

    def _render_header(self) -> None:
        state = self.store.state
        session_id = state.active_session_id
        name = next((s.name for s in state.sessions if str(s.session_id) == session_id), session_id or "—")
        turn = active_turn_for_session(state, session_id)
        badge = f"[b]{turn.status.value}[/b] {turn.phase.value if turn.phase else ''}".strip() if turn else "idle"
        concurrent = len(state.active_turns)
        self.query_one("#chat-header", Static).update(f"{name} — {badge}" + (f"  ({concurrent} tasks)" if concurrent > 1 else ""))

    def _render_timeline(self) -> None:
        state = self.store.state
        session_id = state.active_session_id
        if session_id is None:
            return
        timeline = self.query_one("#chat-timeline", VerticalScroll)
        for item in session_timeline(state, session_id):
            key = self._key_for(item)
            widget = self._widgets.get(key)
            if widget is None:
                widget = self._make_widget(item)
                self._widgets[key] = widget
                timeline.mount(widget)
            else:
                self._update_widget(widget, item)
        if self._last_session != session_id:
            self._last_session = session_id
            timeline.scroll_end(animate=False)
        self._last_session = session_id
```

`_key_for`: `message_id` for text/reasoning/plan, `card.tool_call_id` for tool, `request.interaction_id` for interaction, `turn_id` for user. `_make_widget`: `Static(Markdown(text))` for user/assistant (classes `msg-user` / `msg-assistant`); `Collapsible(Static(""), title="Reasoning", collapsed=not item.streaming)` for reasoning; Task 4 wires the rest. `_update_widget`: re-`update()` the Static with the new text; keep the Collapsible expanded while streaming, collapse when done.

class Composer(TextArea):
    BINDINGS = [
        Binding("enter", "submit", "Submit", priority=True),
        Binding("shift+enter", "newline", "New line", priority=True),
        Binding("ctrl+enter", "newline", "New line", priority=True),
        Binding("ctrl+up", "history_prev", "Previous input", priority=True),
        Binding("ctrl+down", "history_next", "Next input", priority=True),
    ]

    def __init__(self, *args, **kwargs) -> None:
        super().__init__(*args, **kwargs)
        self._history: list[str] = []
        self._history_index = 0

    def push_history(self, text: str) -> None:
        if self._history and self._history[-1] == text:
            return
        self._history.append(text)
        self._history_index = len(self._history)

    def action_history_prev(self) -> None:
        if not self._history:
            return
        self._history_index = max(0, self._history_index - 1)
        self.text = self._history[self._history_index]

    def action_history_next(self) -> None:
        if not self._history:
            return
        self._history_index = min(len(self._history), self._history_index + 1)
        self.text = self._history[self._history_index] if self._history_index < len(self._history) else ""

class FakeTool:
    def __init__(self, name: str, *, result_status: ToolExecutionStatus = ToolExecutionStatus.SUCCEEDED) -> None:
        self.name = name
        self.calls = 0
        self.result_status = result_status
        self._descriptor = ToolDescriptor(name, name, JsonObject(), ("execute",))

    @property
    def descriptor(self) -> ToolDescriptor:
        return self._descriptor

    async def classify(self, invocation: ToolInvocation) -> KernelResult[OperationScope]:
        return KernelResult.success(OperationScope.EXTERNAL)

    async def execute(self, invocation, context, cancellation, output) -> ToolResult:
        self.calls += 1
        now = datetime.now(timezone.utc)
        return ToolResult(invocation.tool_call_id, self.name, self.result_status,
                          (TextBlock("tool ok"),), now, now)

class FakeToolRegistry:
    def __init__(self, *tools: FakeTool) -> None:
        self.by_name = {tool.name: tool for tool in tools}

    async def list(self) -> tuple[ToolDescriptor, ...]:
        return tuple(tool.descriptor for tool in self.by_name.values())

    async def get(self, name: str) -> KernelResult[ToolPort]:
        tool = self.by_name.get(name)
        if tool is None:
            return KernelResult.failure(KernelError(ErrorCode.TOOL_NOT_FOUND, f"No tool {name}."))
        return KernelResult.success(tool)

    async def reload(self) -> KernelResult[tuple[ToolDescriptor, ...]]:
        return KernelResult.success(tuple(tool.descriptor for tool in self.by_name.values()))
```

def history_messages(messages: tuple[Message, ...], session_id: str, base: int = 0) -> tuple[ChatMessage, ...]:
    """History records are committed and complete. User messages are skipped:
    user bubbles come exclusively from user_turns (events never carry them)."""
    records = []
    for offset, message in enumerate(messages):
        if message.role is MessageRole.USER:
            continue
        records.append(ChatMessage(
            str(message.message_id), session_id, "", base + offset + 1,
            message.role, message.kind, message.content, complete=True,
        ))
    return tuple(records)
```

## Escalated ambiguities

1. **Plan-message identification** — `MessageEvent` carries no `MessageKind`; the TUI infers a plan by marking the turn's latest assistant message when a `PLAN_APPROVAL` interaction is requested. Alternative (kernel change: emit `kind` on `MessageEvent`) is out of scope for this gate.
2. **"Foreground turn" definition** — chosen: the active session's turn (`active_session_id`), no-op otherwise; an alternative reading ("most recently started turn") is not used because "switching sessions doesn't cancel background turns" implies the selected session is the foreground.
3. **User bubbles** — events never carry user messages (verified in `TurnEngine._execute`), so the TUI inserts its own `UserTurn` records at submit time and recovery drops USER messages from history. Consequence: sessions with pre-existing history that were never submitted from this app render assistant messages only (no old user prompts) — cosmetic, deferred to the Sessions gate.
4. **Recovery cannot recover a not-yet-committed message's lost deltas** — `conversations.history` only holds committed messages; the merge keeps store-only in-flight records, and the next delta/`completed` event (full replacement) restores content. A gap that loses the *only* delta of an uncommitted message leaves that message blank until the next event.
5. **30 FPS semantics** — render batching only (Textual refresh throttle); the store reducer applies every event synchronously on the UI thread.
6. **Composer history** is per-app-lifetime widget state (not persisted); `Ctrl+Up/Down` never leaves the Composer.
7. **Countdown expiry** — the kernel broker resolves expiry with the fail-closed `safe_default` (REJECT/STOP) and emits `INTERACTION resolved`; the TUI only displays the countdown and never calls `respond` on expiry.

# Kairo TUI 重构说明

当前 TUI 已切换为聊天优先壳层。聊天时间线和输入器是唯一的主工作区；会话、工作区、记忆、扩展、设置和诊断通过 `Ctrl+P` 命令面板、斜杠命令或全屏浮层进入。Kernel 事件、审批、计划编辑、停止和会话持久化路径保持不变。

## 快捷键

默认 Leader 是 `Ctrl+X`，等待后续键 2 秒：

| 操作 | 快捷键 |
| --- | --- |
| 命令面板 | `Ctrl+P` |
| 新会话 | `Ctrl+X`，`N` |
| 会话列表 | `Ctrl+X`，`L` |
| 侧栏 | `Ctrl+X`，`B` |
| 压缩上下文 | `Ctrl+X`，`C` |
| 模型/配置档 | `Ctrl+X`，`M` |
| Thinking | `Ctrl+T` |
| 停止当前 turn / 关闭浮层 | `Esc` |
| 提交输入 | `Enter` |
| 输入换行 | `Shift+Enter`、`Ctrl+Enter`、`Alt+Enter` |

旧的 `Ctrl+1…Ctrl+7`、`Ctrl+K`、`Ctrl+N`、`Ctrl+A` 仍作为兼容别名保留，但新界面不再显示永久导航栏。

## 响应式规则

- 140 列以上：聊天区全宽，侧栏通过 Leader `B` 主动打开。
- 100–139 列：默认聊天区，侧栏打开后占用右侧 42 列。
- 80–99 列：工具全部使用浮层，侧栏覆盖显示。
- 小于 80 列或高度不足：压缩状态提示和边距，但聊天与输入器继续可用。

## 兼容边界

TUI 只依赖 `kairo_kernel` 公共门面、`AppStore` 和事件泵。旧管理 Screen 仍保留为迁移兼容实现，并在命令面板中以 `ManagementModal` 承载；它们不得直接访问 Kernel 内部模块、数据库或工具注册表。安装入口、`kairo`、`kairo-tui`、`run.bat` 和 `run-tui.bat` 不因本次界面重构改变。
